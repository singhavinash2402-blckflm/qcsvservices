# Visual asset register

**Document type:** Living register of images and brand files
**Purpose:** Record where every image on the website came from and whether it may be used.
**Status:** Inventory below is generated from the repository. Source and licence columns still
need to be filled in for every photograph.

## Brand identity

| Asset                                                      | Files                                                                                                                          | Source                                                 | Status                 |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------ | ---------------------- |
| Logo (full, compact, mark, one-colour), icons, share image | `public/brand/`, `public/icons/`, `public/og-default.jpg`, `src/app/icon.svg`, `src/app/favicon.ico`, `src/app/apple-icon.png` | Client's approved brand board, redrawn as vector files | Approved by the client |

The logo is traced from a small board image. Ask the client or a designer for a master vector
before any large-format printing.

## Photography

Before launch, add for each image: where it was downloaded from (page link), the photographer
or contributor, the licence (for example Unsplash, Pexels or Pixabay licence), and the date.
Keep a screenshot of the licence page if the source is not one of those three. Replace any image
whose licence cannot be confirmed.
