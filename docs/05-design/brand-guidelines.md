# Brand guidelines

Practical rules for using the QCSV Services identity. The master reference is the client's
approved brand board; this page records how the website applies it.

## Colours

| Role                  | Value                           | Where                                |
| --------------------- | ------------------------------- | ------------------------------------ |
| Brand navy            | `#0B3566`                       | Logo wordmark, app icon tile         |
| Brand blue            | `#007BFF`                       | Logo mark gradient                   |
| Brand teal            | `#00C2A8`                       | Logo mark gradient, taglines         |
| Brand light teal      | `#A7E6D9`                       | Soft highlights                      |
| Website accent (teal) | `#0E7C86`                       | Buttons, links, labels               |
| Website accent text   | `#0A5C64` light, `#6FD0D8` dark | Small accent text, for contrast      |
| Dark bands            | `#0B0F14`                       | Stories section, call-to-action band |

The site keeps its own teal accent because white text on the brighter brand blue does not meet
contrast guidance for small text. Keep body text high contrast.

## Logo files

All files are in `public/brand/`.

| File                                            | Use                                                  |
| ----------------------------------------------- | ---------------------------------------------------- |
| `logo-horizontal-color.svg`                     | Full logo with tagline on white or light backgrounds |
| `logo-horizontal-for-dark-bg.svg`               | Full logo on dark or photo backgrounds               |
| `logo-compact-color.svg` and `-for-dark-bg.svg` | No tagline. Website header and other small spaces    |
| `logo-mark-*.svg`                               | The infinity mark alone: avatars, watermarks, icons  |
| `logo-horizontal-black.svg` / `-white.svg`      | One-colour printing, stamps, engraving               |
| `app-icon.svg`                                  | Navy tile for favicon and app icons                  |

## Using the logo

- Keep clear space around the logo equal to about the height of the letter Q in the wordmark.
- Smallest sizes: full logo about 44 px high, compact logo about 28 px high, mark about 16 px.
- Do not stretch, rotate, recolour, add shadows or outlines, or place on busy images without an
  overlay. Do not rebuild the wordmark in another typeface.
- Use the dark-background version on dark colours and photos. Never put the colour version on
  navy or black.

## Typography

- Website: Instrument Sans (headings bold, tight letter spacing; body regular).
- Logo lettering is artwork, not a font. Do not retype it.

## Photography

- Real-looking settings: laboratories, clean rooms, manufacturing floors, offices, data centres.
- Avoid images that imply certifications or approvals (for example ISO seals) unless the client
  holds them. Avoid fake dashboards with readable brand names.
- Record the source and licence of every photo in `docs/05-design/asset-register.md`.

## Voice

Plain English, UK spelling, short sentences. Say what QCSV does. Do not claim results,
awards, certifications or client names that the client has not provided.
